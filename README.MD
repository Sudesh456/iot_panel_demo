#IoT Control Panel Demo
A basic web-based control panel that simulates turning an IoT device ON/OFF.
Built as a demo project for the IoT Developer intern role at Vampior Designs, Kurunegala.
**Live Demo**:
https://Sudesh456.github.io/iot_panel_demo/
 
###Features
-ON/OFF buttons to control device state
-Visual feedback with background color change.
-Saves last state using localStorage.
-Mobile responsive design.
-Timestamp of last command.

###Tech Used
-HTML
-CSS
-JavaScript
-GitHub for hosting

###Why I built this
I'm currently practicing web development and applying for IoT internships. This project demonstrate how a frontend dashboard can interface with IoT devices. Next step: learn to connect this to real hardware using REST APIs.

###Future improvements
-Connect to Node.js backend.
-Add real-time data charts.
-ESP32 integration for actual device control.
